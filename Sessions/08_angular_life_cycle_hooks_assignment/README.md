# this is book listing application 

## features
- add book
- edit book
- delete book
- view book
- toast message

## life cycle hooks called when actions occur:

### 1. OnChanges
- when book data is changed , through @Input() decorator

### 2. OnDestroy
- when component is closed

### 3. OnInit
- when data is initialized

### 4. OnContentInit
- when content is initialized , this is called first before the view

### 5. OnViewInit
- when view is initialized
